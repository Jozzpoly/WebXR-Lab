# Riftworks

Fresh reboot of this repository into a new engineering-sandbox prototype.

The previous WebXR proof, Reactor Defense, mixed-reality spikes, and their infrastructure are no longer active project state. They remain only in Git history as donor evidence that browser WebXR on a physical Quest 2 worked.

## Current intent

Riftworks is an experimental machine-building sandbox centered on a short creative loop:

> build → run → observe → modify → run again

The project should favor direct construction, mechanical causality, permissive experimentation, and emergent behavior over authored content breadth.

## Current state

**Fresh foundation. No gameplay architecture is accepted yet.**

The next stage is to establish a desktop-first testable foundation before expanding the game:

- cheap desktop interaction for Owner testing;
- WebXR emulation for controller/event-path testing where useful;
- a small authored machine truth independent from renderer/input/physics runtime;
- disposable runtime physics compiled from authored state;
- only then the first real construction grammar and RUN loop.

Old WebXR code is historical donor material, not architecture authority.
